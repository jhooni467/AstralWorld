# AstralWorld

Aplicación audiovisual independiente con dos experiencias: **Local** y **Online**.

## Identidad visual
Tema inicial: **Aurora Celestial**.

- Midnight Blue: `#101F35`
- Steel Blue: `#244C68`
- Aurora Turquoise: `#65C9C2`
- Mint: `#B5E6D5`
- Solar Gold: `#F4D69A`

## Navegación
- Modo Local: Explora · Biblioteca · Ajustes
- Modo Online: Inicio · Perfil · Ajustes

## Base técnica
HTML, CSS y JavaScript. La estructura está preparada para evolucionar como PWA y, posteriormente, empaquetarse para Android.

## Estado
Versión inicial 0.1. La navegación y el cambio de modo funcionan. La importación local y la reproducción online todavía están pendientes de desarrollo.
